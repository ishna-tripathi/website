# Ishna Tripathi — Astrophysics Portfolio

A static personal portfolio website designed for PhD, research, data and AI applications.

## Files

- `index.html` — website structure and content
- `style.css` — complete visual design and responsive layout
- `script.js` — animated starfield, cursor glow, navigation and reveal animations
- `Ishna_Tripathi_CV.pdf` — CV linked from the site

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

1. Create a GitHub repository, e.g. `ishna-tripathi.github.io`.
2. Put all files from this folder into the repository root.
3. Commit and push.
4. On GitHub go to **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main`, and choose `/ (root)`.
6. Your site will be available at your GitHub Pages URL.

## Before publishing

- Replace/add individual project repository links in `index.html`.
- Add LinkedIn if you want it in the contact section.
- Replace the CV PDF when you update your CV.
- Check that your email address is the one you want publicly visible.

The visual concept is intentionally inspired by the strong editorial / event-page feel of the reference site, but the layout, content and astrophysics visual identity are original.
